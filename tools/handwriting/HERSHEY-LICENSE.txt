Hershey font data: data/hershey-occidental.json

The data is the Hershey occidental vector font set as JSON, from https://github.com/scruss/python-hershey
(hershey-occidental.json; the original Usenet distribution reformatted; the JSON conversion is CC0 / WTFPL).
Checked 2026-11-15 against that repository's README and https://web.mit.edu/ghostscript/src/gs6.01/doc/Hershey.htm.
